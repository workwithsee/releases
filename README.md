# S.E.E. downloads

Download the S.E.E. application from this repository's [Releases](https://github.com/workwithsee/releases/releases). Downloads require no GitHub account or beta signup. The application source remains private.

Please do not share the beta download links.

To update, download the newer release and run its installer or replace the portable application, following that release's platform instructions. Updates are manual; an automatic application updater is not provided.
